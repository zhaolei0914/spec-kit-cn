## 🚨 常见问题

### Q1: 如何确定项目名称 [PROJECT_NAME]？
**A**: 从 `.specify/skills/[PROJECT_NAME]/SKILL.md` 的路径中提取，或从 `pyproject.toml` 的 `name` 字段读取。

### Q2: 如果某个 Wiki 文件不存在怎么办？
**A**: 在工作流中添加条件检查：
```bash
if [ -f .specify/wikis/[PROJECT_NAME]/overview.md ]; then
    cat .specify/wikis/[PROJECT_NAME]/overview.md
fi
```

### Q3: 如何避免 token 超限？
**A**: 
- 只加载当前阶段需要的上下文（L1/L2/L3 分层）
- 对于大文件，只读取相关章节
- 使用 `head -n 100` 限制行数

### Q4: 如何验证 LLM 是否真的使用了上下文？
**A**: 
- 在生成的代码中检查是否符合 SKILL.md 规范
- 在 design.md 中检查是否参考了 Memory 设计决策
- 在 execution-log.md 中记录上下文使用情况
