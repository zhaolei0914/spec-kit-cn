# 主动式项目上下文提取系统设计

## 一、系统目标

构建一个**主动式**的项目上下文提取系统，能够：
1. **自动发现**项目中的所有开发规范和知识点
2. **无需预定义**关键词或模式，通过分析代码自动推断
3. **生成完整的**上下文文档，让新人快速理解项目并开发功能

## 四、提取器详细设计

### 4.1 结构提取器 (StructExtractor)

| 提取项 | 数据源 | 提取方法 | 输出 |
|--------|--------|----------|------|
| 目录结构 | 文件系统 | 递归遍历 | 目录树、文件统计 |
| 服务划分 | 目录名、配置 | 模式匹配 | 服务列表、边界 |
| 技术栈 | requirements.txt, setup.py | 解析依赖 | 框架、库、版本 |
| 模块依赖 | import 语句 | AST 分析 | 依赖图、核心模块 |

### 4.2 代码提取器 (CodeExtractor)

| 提取项 | 数据源 | 提取方法 | 输出 |
|--------|--------|----------|------|
| 代码模式 | AST | 模式挖掘 | 装饰器、继承、命名 |
| 常量定义 | 模块级赋值 | AST + 正则 | 常量列表、分类 |
| 错误码 | *_errorcode.py | 正则 + AST | 错误码、描述、解决方案 |
| 异常类 | class 定义 | AST | 异常层次、用途 |
| 日志模式 | logging 调用 | 正则 | logger 名称、级别 |
| 配置读取 | settings, config | AST | 配置项、默认值 |

### 4.3 业务提取器 (BizExtractor)

| 提取项 | 数据源 | 提取方法 | 输出 |
|--------|--------|----------|------|
| 数据模型 | models.py | AST | 模型、字段、关系 |
| API 契约 | View 类, urls.py | AST + 路由 | 端点、参数、响应 |
| 业务流程 | Handler, Service | 调用链分析 | 流程图、状态转换 |
| 领域术语 | 类名、函数名 | 驼峰/下划线分解 | 术语表 |

### 4.4 文档提取器 (DocExtractor)

| 提取项 | 数据源 | 提取方法 | 输出 |
|--------|--------|----------|------|
| README | README.md | Markdown 解析 | 项目描述、使用说明 |
| Docstring | 函数/类 docstring | AST | 参数说明、返回值 |
| 注释 | # 注释 | 正则 | 上下文注释 |
| 设计文档 | docs/*.md | Markdown 解析 | 设计决策、架构 |

### 6.2 生成原则

1. **真实代码优先**：示例来自项目代码，而非模板
2. **统计数据支撑**：用数据说明规范的普遍性
3. **场景驱动**：按开发场景组织，而非按技术分类
4. **渐进式**：从简单到复杂，从必须到可选

## 八、提取器接口定义

```python
from abc import ABC, abstractmethod
from typing import Dict, List, Any
from dataclasses import dataclass


@dataclass
class KnowledgeItem:
    """知识项"""
    type: str           # 知识类型
    key: str            # 唯一标识
    value: Any          # 知识内容
    source: str         # 来源（文件路径）
    line: int           # 行号
    confidence: float   # 置信度 (0-1)
    priority: int       # 优先级 (1-4)
    metadata: Dict      # 元数据


class BaseExtractor(ABC):
    """提取器基类"""

    @abstractmethod
    def extract(self, source_dir: str) -> List[KnowledgeItem]:
        """提取知识"""
        pass

    @abstractmethod
    def get_supported_types(self) -> List[str]:
        """返回支持的知识类型"""
        pass


class StructExtractor(BaseExtractor):
    """结构提取器"""

    def get_supported_types(self) -> List[str]:
        return ['directory', 'service', 'tech_stack', 'dependency']


class CodeExtractor(BaseExtractor):
    """代码提取器"""

    def get_supported_types(self) -> List[str]:
        return ['pattern', 'constant', 'error_code', 'exception', 'log', 'config']


class BizExtractor(BaseExtractor):
    """业务提取器"""

    def get_supported_types(self) -> List[str]:
        return ['model', 'api', 'flow', 'term']


class DocExtractor(BaseExtractor):
    """文档提取器"""

    def get_supported_types(self) -> List[str]:
        return ['readme', 'docstring', 'comment', 'design']
```

## 九、使用方式

```bash
# 完整提取
python main.py extract-all --source ./src --output ./skills/

# 增量更新
python main.py extract-all --source ./src --output ./skills/ --incremental

# 指定提取器
python main.py extract --extractor code --source ./src --output ./skills/

# 生成文档
python main.py generate --skeleton ./cache/skeleton.json --output ./skills/
```
